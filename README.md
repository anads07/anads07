### 💼 Projetos em destaque

🔹 **Serene**  
https://github.com/anads07/SereneTcc.git

Aplicativo de bem-estar e saúde mental desenvolvido com **React Native**, com funcionalidades como diário emocional, sugestões de autocuidado e acompanhamento do estado emocional do usuário. O projeto foi desenvolvido com foco em experiência do usuário, organização de componentes e estruturação de funcionalidades voltadas ao cuidado com a saúde mental.

🔹 **Reporte Já**  
https://github.com/anads07/ProjetoReporteJa  

Aplicativo mobile desenvolvido com **React Native** para registro e acompanhamento de ocorrências em condomínios. Permite que moradores registrem problemas com descrição, fotos e localização, enquanto a administração pode visualizar e gerenciar as ocorrências registradas.

🔹 **Jogo Termo**  
https://github.com/anads07/jogo-termo  

Implementação do jogo estilo **Wordle**, desenvolvida utilizando **HTML, CSS e JavaScript**. O projeto explora lógica de programação, manipulação do DOM e construção de uma interface responsiva e interativa.
